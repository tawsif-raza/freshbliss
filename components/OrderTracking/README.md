OrderTracking is the live order page: an ETA headline, a Live indicator, the five-step status timeline (Order Confirmed, Preparing, Packed, Out for Delivery, Delivered), a route view with a moving rider marker, a help and actions card, and the order contents.

Provide `order` (`id`, `status`, `etaMinutes`, `etaTotal`, `timestamps`, `items`, `address`, and optionally `pin`, `rider {name, phone, vehicle}`). For real time pass `subscribe(orderId, onUpdate)` that returns an unsubscribe function, the shape of a Firestore `onSnapshot` on `orders/{id}`, and call `onUpdate` with partial patches. `simulate` runs a demo feed instead. The help card offers Share tracking (`shareUrl`, native share sheet or copy link), Copy order ID, Get help (`onHelp`), and Cancel order, which is available until the order is packed and asks for a reason before calling `onCancel(orderId, reason)`; the server must enforce the same rule. While out for delivery it shows the delivery code (`order.pin`) and Call rider / Message buttons. When delivered it offers Order again (`onReorder`) and a `FeedbackForm` (`onFeedback`). A `CANCELLED` status shows a warning callout, and later snapshots never overwrite a local cancel. Statuses always carry text, never color alone. The route view shows status and ETA only; live driver GPS needs a delivery-partner app and is a later phase.
