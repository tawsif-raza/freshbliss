A11yPanel is the customer-facing accessibility settings control: a button that opens colour theme (Match my device, Cream, Forest, High contrast), motion (Follow my device, Reduce motion) and text size (Default, Large, Larger), with a reset and a status line.

Wrap the whole app in `A11yProvider` (optionally `skipTo="fbs-main"` to add a Skip to main content link, and `storageKey`), then place `A11yPanel` in the navigation. Choices are stored on the device (localStorage, ignored if blocked) and applied as `data-theme`, `data-text` and `data-motion` on the provider's wrapper. Colour theme defaults to the device: `prefers-contrast: more` selects High contrast and `prefers-reduced-motion` is always honored. High contrast is an added theme: text is 7:1 or better and borders are 3:1 or better on every surface. Text size scales the whole wrapper with CSS `zoom`. Reduce motion stops the hero parallax, scroll reveals, 3D auto-rotation and all transitions. Controls are at least 44px tall and fully keyboard operable; Escape closes the panel and returns focus to its button. Give the page `<main id="fbs-main" tabIndex={-1}>` (HomeScreen already does) so the skip link has a target.
